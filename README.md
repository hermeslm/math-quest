# 🦉 Division Quest — Grade 4 Math, Topic 5

Free, interactive, randomly generated division practice for 4th graders, in **English and Spanish**. It follows the enVision Florida Mathematics **Topic 5: Divide by 1-Digit Numbers** lessons (5-1 to 5-11). Each lesson has a **Help at Home** page for parents, with the lesson animations, a practice example and a home activity.

▶️ **Play:** https://&lt;your-username&gt;.github.io/&lt;repo-name&gt;/ (on a tablet, use *Add to Home Screen*)

- The app is in [`division-quest/`](division-quest/). See its [README](division-quest/README.md) for features, files and how to run it locally (just open `index.html`).
- It is published by [`.github/workflows/pages.yml`](.github/workflows/pages.yml) on every push to `main`.
